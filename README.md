# Портфолио Марины Захаровой

Одностраничный сайт-портфолио: HTML + CSS + JavaScript, анимации на GSAP + ScrollTrigger, плавный скролл на Lenis. Сборка не нужна.

Дизайн: графитовый фон с диагональными плоскостями, острые формы и один акцентный цвет, нежно-розовый `#f4b4c4`. Чтобы сменить оттенок, поменяй `--accent` в начале `style.css`.

## Структура

```
index.html   — разметка и тексты
style.css    — стили и адаптив
script.js    — данные (навыки, проекты), все анимации и интерактив
resume.pdf   — резюме для скачивания
```

## Запуск локально

Достаточно открыть `index.html` двойным кликом. Нужен интернет: шрифты и библиотеки анимаций грузятся с CDN. Если их нет, сайт всё равно работает, просто без анимаций.

Для удобной разработки с автообновлением подойдёт расширение VS Code **Live Server**: правый клик по `index.html` → «Open with Live Server».

## Деплой

**GitHub Pages:** создай репозиторий, загрузи файлы, затем Settings → Pages → Branch: `main` / root. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify:** перетащи папку проекта на https://app.netlify.com/drop.

**Vercel:** `npx vercel` в папке проекта.

## Что нужно заменить на своё

| Где | Что |
|---|---|
| `script.js` → массив `PROJECTS` | **Главное.** Сейчас там 3 примера-заглушки. Замени на свои реальные проекты: курсовые, лабы, pet-проекты, хакатоны. Поле `viz` задаёт картинку: `terminal`, `db` или `chart` |
| `script.js` → массив `SKILLS` | Проверь описания навыков: всё ли там правда и ничего ли не упущено |
| `index.html` → секция «Путь» | Годы и предметы по курсам указаны примерно, поправь под себя |
| `resume.pdf` | Резюме для кнопки «Скачать PDF». Чтобы обновить, замени файл с тем же именем |
| папка проекта → `og-image.png` | Картинка 1200×630 для превью ссылки в Telegram и LinkedIn |
| `index.html` → блок `.contact__links` | Можно добавить строки с GitHub и hh.ru |

Форма в контактах работает без сервера: по кнопке «Отправить» открывается почтовый клиент с уже заполненным письмом на твой адрес.

## Анимации и фишки

- Прелоадер: рисуется символ `</>`, затем шторка уезжает вверх
- Первый экран: розовая полоса «вырастает», заголовок выезжает по буквам, строки кода печатаются, окна и диагональные плоскости следуют за мышью
- Карточки «услуг» заливаются розовым снизу при наведении
- Картинки проектов открываются розовой шторкой, внутри растут столбики графика и появляются таблицы
- Заголовки выезжают по словам, розовые черточки прорисовываются, линия «Пути» тянется по мере скролла, счётчики докручиваются
- Магнитные кнопки, зачёркивание активного пункта меню, мобильное меню-оверлей
- Кейсы проектов в модальном окне: задача → решение → результат
- Пасхалки: сообщение в консоли браузера (F12) и Konami-код ↑ ↑ ↓ ↓ ← → ← → B A
- Поддержка `prefers-reduced-motion`, навигация с клавиатуры, адаптив под телефоны
